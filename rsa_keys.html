Generate Kunci RSA

Di sini kamu dapat menghitung pasangan public key dan private key RSA berdasarkan dua bilangan prima p dan q.

Langkah awal RSA Pembangkitan kunci

Langkah matematis

  • Pilih bilangan prima p dan q.
  • Hitung n = p × q.
  • Hitung φ(n) = (p-1)(q-1).
  • Pilih e relatif prima terhadap φ(n).
  • Cari d sehingga e·d ≡ 1 (mod φ(n)).

Output yang dihasilkan

  • Public key: (n, e)
  • Private key: (n, d)
  • Kamu bisa ekspor keduanya sebagai file JSON untuk digunakan di halaman RSA Encrypt/Decrypt.

Catatan demo

Nilai p dan q di sini hanya contoh kecil, sehingga tidak aman untuk dipakai di dunia nyata. Di implementasi real, p dan q harus sangat besar.

Hitung Parameter RSA

Masukkan dua bilangan prima, lalu sistem akan menghitung n, φ(n), e dan d.

Langkah Perhitungan
